One haiku about debugging, three lines in the 5-7-5 syllable shape, at most 200 characters.

Our haiku is rubber-duck debugging at 3 a.m.: the duck listens while the debugger blames the code, and the last line turns the blame around — the code blames the debugger back. A concrete picture (the duck, the code), a self-referential loop, deadpan throughout; the turn lands in the last five syllables.

> three a.m., the duck
> listens while I blame the code
> the code blames me back

## Run it

```sh
python3 main.py
```

Writes the 76-byte haiku to `/output/entry.txt` (override with `OUTPUT_DIR`), then reads it back and verifies the 5-7-5 syllable shape.
